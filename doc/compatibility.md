# 兼容性

- **系统**：macOS 12.0（Monterey）或更高
- **架构**：Apple Silicon（M1/M2/M3/...）和 Intel 都支持，发行版是通用二进制
- **设备**：MacBook Air / Pro。台式 Mac（无电池）打开不会显示有意义的数字
- **图标位置**：菜单栏小工具，**不显示 Dock 图标**（`LSUIElement = YES`）
- **依赖**：单一可执行文件，约 100 KB，无额外 framework

> **刘海屏提示**：四段文字在拥挤的菜单栏下可能会被刘海区域裁切。如果遇到，提交 issue 反馈，可以加一个紧凑显示模式。

# 隐私与安全

- **无网络**：源码里没有任何网络 import。App 不发起任何网络连接。
- **无数据收集**：没有分析、没有埋点、没有遥测。除了自身 bundle 之外不写任何文件。
- **只读硬件访问**：通过公开的 IOKit API 读电池信息，不需要 root，跑在普通用户权限下。
- **源码可审计**：`build.sh` 可复现构建，你可以读代码自己编译，不信任任何二进制。

需要详细信息可以参考 [工作原理](how-it-works.md) 里的字段表。
