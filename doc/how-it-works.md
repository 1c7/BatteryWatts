# 工作原理

## 状态栏布局

插电时，菜单栏始终显示四个数字，只有最前面的图标会随状态变化：

| 状态 | 示例 | 含义 |
|:---:|:---|:---|
| `⚡` | `⚡ 30/100W · 2:15 · 68% · 32°C` | 正在充电 |
| `🔌` | `🔌 0/100W · --:-- · 41% · 32°C` | 接入电源，充电脉冲间隙（正常） |
| `⏸` | `⏸ 0/100W · --:-- · 41% · 🌡️40°C` | 充电已持续停止约 2 分钟（如热保护、电池保护模式） |
| `🔋` | `🔋 82% · 剩余 3:29` | 拔电使用电池 |

> **关于 `🔌` 和 `⏸` 的区别**：macOS 的充电是脉冲式的，每分钟会在「充电」和「短暂不充电」之间切换几次。单次采样到「没在充电」不代表真的停了。只有连续约 2 分钟没充电才显示 `⏸`，这才是值得注意的状态。

## 数字含义

- **充电瓦（W）**：当前真正流进电池的功率 = 电压 × 电流
- **充电器瓦**：本次插电以来充电器输出过的最高功率（macOS 不会暴露充电器的标称功率，只能观察实际谈判值）
- **剩余时间**：用 macOS 自己的预估（和 `pmset` 一致）
- **电池温度**：过温阈值时前面加 🌡️ 并发系统通知

## 充电瓦数为什么看起来比充电器额定值低

这是正常现象。MacBook 只在「电池低 + 系统重载」时才会按充电器满功率拉电。随着电量上升，充电会自然降速——14% 时显示 `29/100W` 完全正常。观察它先升后降的曲线即可。

## 充电器数字为什么有时低

同上：macOS 暴露的是「当前谈判的 USB-C PD 功率」，会随充电阶段变化。「充电功率」记录本次插电的最高值作为充电器能力的代表。如果你插电时电池已经接近满电，可能要等真实负载出现才会看到满功率。

## 实现

App 是一个 Swift 单文件 [`src/main.swift`](../src/main.swift)，每 5 秒读一次 IOKit 注册表里的 `AppleSmartBattery`，把字符串画到 `NSStatusItem`。读到的字段：

| IOKit 键 | 用途 |
|---|---|
| `Voltage`(mV) × `Amperage`(mA) | 充电功率 |
| `AdapterDetails.Watts` | 充电器最大功率 |
| `AvgTimeToFull`(分钟) | 距离充满 |
| `AvgTimeToEmpty`(分钟) | 电池续航剩余 |
| `AppleRawCurrentCapacity` / `AppleRawMaxCapacity` | 电量百分比 |
| `ExternalConnected` / `IsCharging` / `FullyCharged` | 插电/充电状态 |
| `Temperature` | 电池温度（百分之一摄氏度） |

读出来的数据与 `pmset -g batt`、`system_profiler SPPowerDataType` 完全一致。
